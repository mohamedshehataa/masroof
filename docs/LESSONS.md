# Lessons

Every escaped defect, failed gate pattern or SDLC friction becomes one entry: **what happened → root cause (spec gap / test gap / review miss / environment) → prevention (test, rule, hook or checklist item)**.

- 2026-10-23 — Tooling installed mid-session (winget) is not on the PATH of already-running processes → environment → `scripts/env.sh` is sourced by every hook and the Makefile so PATH never depends on how the shell was started.
- 2026-10-23 — A single very large `bash -c` script with a dozen heredocs failed to parse and wrote nothing → environment → write files one per tool call; keep shell batches small so a failure is local and visible.
- 2026-10-23 — The commit-msg lint required lowercase scopes while the skills commit as `docs(STORY-NNN): ...` → test gap (two artefacts, no shared fixture) → lint now accepts `[A-Za-z0-9]` scopes and its test suite covers a story-id scope.
- 2026-10-23 — The stop-gate blocked a stop while a subagent was mid-edit (duplicate REQ across two story files) → environment → expected and correct; re-run the gate after the subagent finishes rather than editing around it.
- 2026-10-23 — The lefthook `spotless` pre-commit step calls `./gradlew spotlessCheck` whenever a .java file is staged, which cannot succeed before the Spotless plugin exists → environment (bootstrap ordering) → for a module's first story, commit tests and implementation back to back after the build gains its quality plugins; never skip the hook.
- 2026-10-23 — The qa-verifier found 11 MAJOR bypasses in guardrails the orchestrator had written and unit-tested at 242/242 → test gap (tests mirrored the author's mental model) → every guard change is now verified by a fresh-context agent with exploratory probes before the story is DONE; the hook suite grew to 424 cases from those probes.
- 2026-10-24 — STORY-002's hand-written size came out ~2x the design estimate (812 vs 388), almost all in google-java-format-expanded test chains and a shell JUnit writer → spec gap (estimates ignored formatter expansion) → design-stage size checks count the test-designer's files at ~2x for fluent-assertion code.
- 2026-10-24 — `make security` had been RED since bootstrap (osv-scanner 2.7 dropped `--skip-git`; trivy's `--skip-dirs build` misses nested build dirs) and nobody noticed until a security review ran it → test gap (no gate ran make security) → nightly/CI run it; security.sh fixed.
- 2026-10-24 — A session restart stopped two background agents mid-task (one with hooks unlocked in the shared checkout, one with half-regenerated verification metadata in a worktree) and an implementer wrote a backup file outside its worktree → environment → on resume the orchestrator first inventories `git status`, `git worktree list` and `.claude/state.json` before resuming anyone; implementer briefs now say "never write outside your worktree".
- 2026-10-24 — Commits made inside an agent worktree skipped the lefthook hooks ("Can't find lefthook in PATH": worktrees have no root node_modules and the git hook shim does not source scripts/env.sh) → environment → worktree commits are cherry-picked onto the story branch in the main checkout, where the hooks run; follow-up for STORY-016: CI must also lint commit messages and run gitleaks per PR so hook-less commits cannot reach main.
- 2026-10-24 — A test-designer mechanical check encoded an over-broad criterion (any junit 5.14.4 metadata entry) that a correct implementation could not satisfy → spec gap → the implementer stopped with BLOCKED instead of editing the test (the system worked); criteria that ban artefacts now say "resolved jar" vs "pom/BOM import" explicitly.
- 2026-10-24 — SDLC: the PRs for STORY-143 (#3) and STORY-141 (#4) were stacked on the earlier PR branches. When the owner merged them, they landed in those branches, not in `main`, so the two stories needed a re-PR (#8). → Every PR now targets `main`, and a dependent story's PR waits for its parent to merge and then rebases (`.claude/skills/story/integrate.md`).
- 2026-10-25 — STORY-141 verify loop 1 could not start `make`, ran `check-fast.sh web` + `npm run test:coverage` instead of the whole `make check`, and missed the coverage-gate failure (fixed later by 36cca85) → review miss (environment: make is on PATH only after `scripts/env.sh`, and every Bash call is a fresh shell) → qa-verifier agent + prompt and worktree-merge.md: `source scripts/env.sh && make ...` in one call; fallback is the target's full Makefile recipe, never a sub-step (Phase 0 retro).
- 2026-10-25 — The low-tier combined verify+review hit qa-verifier's 60-turn limit (STORY-143, resumed) → environment (one agent does two jobs) → maxTurns 80 + a turn-budget line: with ~10 turns left print the contract with `NOT RUN` items (Phase 0 retro).
- 2026-10-25 — Windows-generated artefacts failed Linux CI: Gradle verification metadata (PR #2), yamllint wording, screenshot baselines → environment → backend/CLAUDE.md and web/CLAUDE.md say to regenerate those in the Linux images (Phase 0 retro).
- 2026-10-25 — `make metrics` run in a fresh retro worktree rewrote gate failures 51 → 10 and coverage to "no report" (gitignored `.claude/state/` and build reports are absent there) → environment → retro SKILL: quote the committed metrics, read state from the main checkout, never commit a worktree regeneration.
- 2026-10-25 — STORY-007: semgrep findings in a test file surfaced only in PR CI after two local verify loops, because `make check` doesn't run semgrep → verifiers run `make security` (or the PR's live CI) before reporting PASS on any story that adds or changes code files.
